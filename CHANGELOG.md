# Изменения

## 2.0.0

Tapkofon теперь устанавливается как Python-пакет и запускается командой `tapkofon`. Веб-клиент по-прежнему работает без JavaScript.

### Что изменилось

- Добавлен вход в Telegram по QR-коду в браузере и терминале.
- Настройки браузера, избранные чаты, черновики и данные кеша хранятся в SQLite. Приложение применяет миграции при запуске.
- Добавлены текстовый режим, страницы по 5/10/20 элементов, фильтры непрочитанных и избранных чатов, быстрые ответы и отдельная форма сообщения.
- Пароль доступа хранится как Argon2id-хеш. Веб-сессии имеют срок действия, POST-формы защищены CSRF-токенами, попытки ввода пароля ограничены.
- Для изображений доступны размеры под экран телефона. Аудио можно преобразовать в MP3, а речь распознать через Google. Распознавание можно отключить.
- Команды CLI управляют запуском сервера, входом в Telegram, паролем и миграциями базы.
- Добавлены тесты и CI для Python 3.12, 3.13 и 3.14 на Linux и Windows, а также проверка запуска Docker-контейнера.

### Исправления истории

- Чат отмечается прочитанным после загрузки сообщений и формирования HTML. Граница отметки совпадает с ID самого нового показанного сообщения. Просмотр старой истории, пустая страница и ошибка подготовки страницы не отправляют отметку.
- Переходы по истории используют курсоры `before` и `after`. Новые сообщения и удаления перед границей больше не сдвигают следующую страницу. Параметр `page` остаётся только у списка чатов.

### Обновление со старой версии

1. Остановите сервер и сохраните копию папки `session/`. Если задан `TAPKOFON_DATA_DIR`, сохраните этот каталог.
2. Установите uv. Для конвертации аудио нужен FFmpeg в `PATH`.
3. Установите wheel из релиза через `uv tool install --python 3.14`, затем запустите `tapkofon` с прежним каталогом данных через `--data-dir`. Команда установки приведена в README.
4. Существующие `config.toml` и Telegram-сессия сохраняются. При первом запуске приложение переносит общие настройки из TOML в SQLite.

Вместо `run.sh` используйте `tapkofon`. Скрипты `local_deploy.sh`, конфигурация Okteto и старые CLI-флаги удалены. Основной способ установки теперь uv, альтернатива pipx. pip не рекомендуется.

Перед внешним доступом задайте пароль. Для доступа через интернет нужны HTTPS и `cookie_secure = true`. Приложение обслуживает один Telegram-аккаунт и должно работать с одним worker.
